# Перекличка

Інструмент для відмітки відвідуваності дітей та швидкої перевірки укриття під час тривоги.
Порт на **pnpm + TypeScript + Vite**, той самий функціонал, що й у попередній однофайловій HTML-версії.

## Технології
- [Vite](https://vite.dev) — збірка та дев-сервер
- TypeScript (strict mode)
- Без фреймворків — прямий DOM API
- Дані зберігаються в `localStorage` браузера (нічого не йде на сервер)

## Структура

```
src/
  types.ts        — типи (ClassRecord, Student, SessionRef, MarkMap)
  storage.ts       — вся робота з localStorage
  sort.ts           — сортування А-Я та за номером/літерою класу, перевірка унікальності
  dateUtils.ts     — форматування дат українською
  dom.ts            — дрібні DOM-хелпери
  modal.ts          — кастомна модалка підтвердження видалення
  app.ts             — стан застосунку та рендер усіх екранів
  main.ts            — точка входу, підʼєднує кнопки до app.ts
  style.css          — стилі (винесені з колишнього inline <style>)
index.html          — розмітка всіх екранів
```

## Розробка

Потрібен [pnpm](https://pnpm.io) (можна активувати через `corepack enable`).

```bash
pnpm install
pnpm dev        # локальний сервер з гарячим перезавантаженням
pnpm build      # перевірка типів + продакшн-збірка у dist/
pnpm preview    # локальний перегляд production-збірки
```

## Деплой на GitHub Pages

У репозиторії вже є `.github/workflows/deploy.yml` — при кожному push у `main` GitHub
Actions сам зробить `pnpm build` і опублікує вміст `dist/` на GitHub Pages.

Один раз потрібно ввімкнути це в репозиторії:

1. Запуште код у репозиторій на GitHub (гілка `main`).
2. Settings → Pages → Source → виберіть **GitHub Actions**.
3. Після першого push у `main` у вкладці **Actions** з'явиться workflow —
   дочекайтесь зеленої галочки, і в Settings → Pages зʼявиться посилання на сайт.

Далі кожен наступний `git push` автоматично оновлюватиме сайт — вручну нічого
заливати не потрібно.

## Дані та приватність

Усі класи, діти та відмітки зберігаються лише локально в браузері (`localStorage`)
того пристрою, на якому відкритий сайт. Сам код застосунку публічний (це просто
статичний сайт), але жодні імена дітей чи відмітки нікуди не відправляються.
